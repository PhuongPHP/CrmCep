1. YÊU CẦU MÔI TRƯỜNG & CÔNG CỤ CẦN THIẾT

Thành Phần Yêu Cầu Phiên Bản Mô Tả & Hướng Dẫn Kiểm Tra
.NET SDK .NET 8.0 LTS (hoặc 9.0) Mở Terminal kiểm tra: dotnet --version.
Hệ Quản Trị CSDL Microsoft SQL Server (MSSQLSERVER) SQL Server 2019/2022 hoặc SQL Server Express đang chạy trên máy (Localhost).
Công cụ EF Core dotnet-ef CLI Cài đặt toàn cục (nếu chưa có): dotnet tool install --global dotnet-ef.
Trình Duyệt Web Google Chrome, Edge, Firefox Hỗ trợ WebAssembly và HTML5 hiện đại.

2. HƯỚNG DẪN CÀI ĐẶT & CHẠY SOURCE CODE

BƯỚC 1: KIỂM TRA CHUỖI KẾT NỐI DATABASE
Mở tệp src/Presentation/CrmCep.WebApi/appsettings.json để xem chuỗi kết nối:
{ "ConnectionStrings": { // Windows Authentication (Mặc định máy local - Không cần mật khẩu): "DefaultConnection": "Server=localhost;Database=CrmCepDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true;" } }

(Nếu SQL Server sử dụng tài khoản sa có mật khẩu, bạn chỉ cần thay đổi: Server=localhost;Database=CrmCepDb;User Id=sa;Password=MatKhauCuaBan;TrustServerCertificate=True;MultipleActiveResultSets=true;)

BƯỚC 2: CƠ CHẾ AUTO-MIGRATION & AUTO-SEED DỮ LIỆU
Ứng dụng được thiết kế thông minh với cơ chế Auto-Migration & Seed Data tự động. Khi chạy Web API, hệ thống sẽ:
  • Tự động tạo CSDL CrmCepDb nếu chưa tồn tại.
  • Tự động tạo các bảng Customers, Users và bộ chỉ mục Unique Index.
  • Tự động nạp tài khoản Quản trị viên: admin / Admin@123.
  • Tự động nạp sẵn 5 hồ sơ khách hàng vi mô mẫu (Công nhân, Tiểu thương, Lao động tự do) để kiểm thử ngay.
BƯỚC 3: KHỞI CHẠY BACKEND WEB API
Mở một cửa sổ Terminal tại thư mục src/Presentation/CrmCep.WebApi và gõ lệnh:
dotnet run

Hệ thống Web API sẽ khởi động tại: https://localhost:7178 (Swagger UI: https://localhost:7178/swagger).

BƯỚC 4: KHỞI CHẠY FRONTEND BLAZOR WEB UI
Mở một cửa sổ Terminal thứ hai tại thư mục src/Presentation/CrmCep.BlazorUI và gõ lệnh:
dotnet run

Giao diện Web Blazor sẽ chạy tại địa chỉ hiển thị trên màn hình console (thường là https://localhost:7083 hoặc tương đương).

3. HƯỚNG DẪN SỬ DỤNG PHẦN MỀM (USER GUIDE)

3.1. Đăng Nhập Hệ Thống (Xác Thực JWT)

  1. Mở trình duyệt truy cập đường dẫn Web Blazor (hoặc điều hướng đến /login).
  2. Nhập thông tin tài khoản quản trị viên mặc định:
    • Tên đăng nhập: admin
    • Mật khẩu: Admin@123
  3. Nhấn nút "ĐĂNG NHẬP". Hệ thống sẽ xác thực với Web API, cấp mã JWT Bearer Token, lưu vào trình duyệt an toàn và tự động chuyển hướng đến màn hình Quản lý Khách hàng.

3.2. Theo Dõi Chỉ Số Thống Kê (Dashboard KPI)

Ngay đầu trang quản trị, hệ thống cung cấp 04 thẻ KPI trực quan cập nhật theo thời gian thực:

  • Tổng Khách Hàng: Tổng số hồ sơ khách hàng hiện có trong tổ chức.
  • Đang Hoạt Động: Số khách hàng đủ điều kiện tham gia các khoản vay/tiết kiệm vi mô.
  • Tạm Ngưng / Khóa: Số khách hàng đang bị hoãn giao dịch hoặc có rủi ro tín dụng.
  • Mới Trong Tháng: Số khách hàng mới được phát triển trong tháng hiện tại.

3.3. Tìm Kiếm & Lọc Danh Sách Khách Hàng

  • Tìm kiếm tức thời: Nhập Họ tên (ví dụ: "Hùng") hoặc Số điện thoại (ví dụ: "0908") vào ô tìm kiếm và nhấn Enter. Bảng dữ liệu sẽ lọc ngay lập tức.
  • Lọc theo Trạng thái: Lựa chọn dropdown "Đang hoạt động", "Tạm ngưng", hoặc "Đã khóa".
  • Lọc theo Phân loại đối tượng: Chọn lọc theo "Công nhân lao động", "Tiểu thương buôn bán", hoặc "Lao động tự do".

3.4. Thêm Mới Hồ Sơ Khách Hàng

  1. Nhấn nút màu xanh "Thêm Khách Hàng" ở thanh công cụ.
  2. Hộp thoại nhập liệu mở ra:
    • Mã Khách Hàng: Tự động sinh mã chuẩn ngân hàng (ví dụ: KH-2026-XXXX) hoặc có thể nhập theo ý muốn.
    • Họ và Tên: Nhập họ tên đầy đủ (bắt buộc, 2 - 100 ký tự).
    • Số Điện Thoại: Nhập số di động 10 chữ số tại Việt Nam (bắt đầu bằng 03, 05, 07, 08, 09). Hệ thống tự động kiểm tra định dạng và báo lỗi nếu trùng lặp.
    • Hộp Thư Email: Nhập email hợp lệ theo chuẩn RFC.
    • Ngày Sinh: Chọn ngày sinh trên lịch. Hệ thống khóa chặn những người dưới 18 tuổi nhằm đảm bảo năng lực pháp lý giao dịch vi mô.
    • Phân Loại Đối Tượng & Trạng Thái: Chọn nhóm ngành nghề và trạng thái hoạt động.
    • Địa Chỉ & Ghi Chú: Nhập nơi cư trú/làm việc và ghi chú hồ sơ.
  3. Nhấn "Lưu Hồ Sơ". Thông báo Toast màu xanh hiển thị thành công và bản ghi mới xuất hiện ngay trên bảng.

3.5. Chỉnh Sửa Thông Tin Khách Hàng

  1. Tại dòng khách hàng cần sửa, nhấn vào Biểu tượng Chiếc Bút (Sửa) ở cột Thao tác.
  2. Hộp thoại chỉnh sửa xuất hiện với đầy đủ thông tin hiện tại (Mã KH được khóa để bảo toàn định danh).
  3. Sửa đổi thông tin cần thiết và nhấn "Cập Nhật".

3.6. Xóa Khách Hàng (Cơ Chế Soft Delete An Toàn)

  1. Nhấn vào Biểu tượng Thùng Rác (Xóa) tại dòng khách hàng muốn xóa.
  2. Hộp thoại cảnh báo màu đỏ xuất hiện để chống bấm nhầm.
  3. Nhấn "Đồng Ý Xóa". Hệ thống sẽ đánh dấu xóa mềm (IsDeleted = true), bảo toàn dữ liệu lịch sử tín dụng trong CSDL vật lý mà không làm mất vết kế toán.

3.7. Xuất Báo Cáo Ra File Excel (.xlsx)

  1. Nhấn nút "Xuất Excel" ở góc trên bên phải thanh công cụ.
  2. Hệ thống backend tự động tạo file Microsoft Excel chuẩn định dạng thương hiệu CEP (có màu sắc tiêu đề, căn chỉnh độ rộng cột, kẻ bảng dữ liệu).
  3. Trình duyệt sẽ tự động tải file Danh_Sach_Khach_Hang_CEP_YYYYMMDD_HHmm.xlsx về máy tính của bạn.
